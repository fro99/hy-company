# 배포본 검증 기록

검증일: 2026-11-05. 이 기록은 시작 프로젝트 자체의 검증이며 학생 계정의 연결·배포 완료를 의미하지 않습니다.

- 실제 ZIP을 별도 임시 폴더에 압축 해제한 뒤 `npm ci`, `npm run typecheck`, `npm run build` 통과.
- Chrome에서 로컬 예시 6건, 디자인 필터 2건, 전체 필터 복귀, 상세 페이지 직접 접근·새로고침, 없는 공고 안내 확인.
- 데스크톱과 모바일 화면 확인. 모바일 가로 넘침과 브라우저 JavaScript 오류 없음.
- 지원 링크 미설정 시 버튼 비활성화. 테스트 HTTPS 링크 설정 시 해당 링크 연결 확인(실제 폼 제출은 하지 않음).
- 실제 Supabase 조회 어댑터를 로컬 모의 REST 서버와 연결해 DB 데이터 표시, 0건, 서버 오류, 연결값 일부 누락을 확인. 오류 시 예시 데이터로 숨기지 않음.
- 초기 SQL을 PGlite 로컬 PostgreSQL 환경에서 실행: 예시 6건, 재실행 중복 없음, unpublished 공고 비공개, anon 쓰기 차단 확인.
- 시작하기.html의 요청 5개 복사 내용 일치 및 모바일 너비 확인.
- ZIP 포함 파일을 명시적으로 제한. 실제 .env.local, .git, .mcp.json, .vercel, node_modules, .next 제외.

실제 학생 Supabase 프로젝트의 DB 생성·네트워크·권한과 GitHub/Vercel 계정 인증·공개 배포는 학생별로 확인해야 합니다. 수업 전 동일 절차로 강사 리허설을 진행하세요.

## 서버 연결 가이드 추가 검증

- `/setup` 서버 페이지의 실제 미연결 상태 표시, 원본 SQL 복사, 환경변수 양식 복사, 모바일 너비와 채용 화면 이동 확인.
- 프로덕션 빌드 통과. Vercel용 파일 추적 목록에 초기 SQL이 포함되는지 확인.

## CLI 프롬프트 방식 업데이트

- `/setup`과 시작하기.html의 같은 CLI 연결 프롬프트를 비교하고 복사 일치를 확인했습니다. 이전 SQL 복사 중심 화면은 교체했습니다.
- Supabase CLI 3.0.0의 `link`, `db push --remote --dry-run` 도움말과 Vercel CLI 65.11.0의 `git connect` 도움말을 확인했습니다. 실제 계정 로그인·프로젝트 생성·원격 DB 변경·배포는 실행하지 않았습니다.
- 시작 프로젝트에는 CLI 설치를 필수 의존성으로 묶지 않습니다. AI가 설치 여부와 버전을 확인하고 필요한 CLI만 준비합니다.
